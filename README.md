# ClipFarm — автоматическая нарезка и выкладка Shorts на несколько каналов

Каждый день по расписанию (бесплатно, на серверах GitHub):

1. берёт футаж кампании с Google Диска;
2. нарезает **новые** моменты: уже использованные запоминаются и не повторяются;
3. раздаёт ролики по каналам, у каждого канала свои ролики без дублей;
4. **выкладывает на YouTube по расписанию** (12:00 / 17:00 / 21:00 и т.п.) через официальный API;
5. присылает в Telegram отчёт со ссылками, которые нужно отправить в Клипни.

Твой компьютер в этом не участвует.

---

## Как работает выкладка (важно)

Выкладка идёт через официальный **YouTube Data API**, без сторонних сервисов. У Google есть правило: ролики, загруженные через новый API-проект, остаются **приватными, пока проект не пройдёт проверку (аудит)**. Аудит бесплатный, но сроки рассмотрения Google не публикует.

Поэтому есть три режима, переключаются одной строкой `"mode"` в `config.json`:

| mode | Что происходит | Когда использовать |
|---|---|---|
| `"telegram"` | готовые ролики с заголовком и временем публикации приходят тебе в Telegram, выкладываешь сам (около 2 минут на ролик) | **сейчас, пока идёт аудит** |
| `"youtube"` | ролики сами загружаются на каналы и публикуются по слотам | **после одобрения аудита** |
| `"local"` | только нарезка, без публикации | для тестов |

## Форматы роликов

Конвейер чередует три формата (`campaign.formats` в `config.json`):

| Формат | Что это | Футаж |
|---|---|---|
| `story` | **озвученная история**: голос Microsoft (edge-tts, 3 попытки, запасной голос), а если он недоступен — **Piper** прямо на сервере GitHub; субтитры по словам, геймплей фоном, звук игры приглушён | фон, кадры можно повторять |
| `list` | **список**: заголовок сверху («Типы игроков в STALZONE»), пункты по одному на кусок геймплея | фон, кадры можно повторять |
| `montage` | **монтаж** из свежих кусков; когда свежие кончились — пересборка старых (`recycle`) | каждый кусок по правилам повтора |

Тексты историй и списков лежат в **`content.json`**. Их можно править и дополнять прямо на GitHub (карандаш ✏️):
- `stories` — `{"title": "...", "text": "..."}`; 80–130 слов ≈ 40–55 секунд. Если озвучка короче 41 секунды, ролик сам дотягивается до 41;
- `lists` — `{"title": "...", "items": ["...", "...", "...", "...", "..."]}`; 5 пунктов по 8–10 секунд;
- `voice` / `voice_backup` — голоса Microsoft (`ru-RU-DmitryNeural` мужской, `ru-RU-SvetlanaNeural` женский), `rate` — скорость (`+0%`, `-5%`, `+5%`);
- `piper_voice` — запасной голос Piper: `dmitri:medium`, `denis:medium`, `ruslan:medium` (мужские), `irina:medium` (женский).

Тексты не повторяются, пока не будет пройден весь банк. В историях и списках смысл несёт текст, а не кадры, поэтому даже небольшого футажа хватает надолго.

## Часть 1. Запуск конвейера (≈30 минут)

### 1. Репозиторий на GitHub
1. На github.com создай **публичный** репозиторий `clipfarm` (New → **Public**). На публичных репозиториях GitHub Actions бесплатны без лимита минут, и конвейер не тратит минуты твоих приватных проектов. Всё чувствительное (токены, ссылка на футажи) лежит в секретах: их не видно ни в коде, ни в логах.
2. Загрузи туда **все файлы из архива**, включая папку `.github` (Add file → Upload files, перетащи содержимое папки).

### 2. Плашка и исходники
- `stalzone.png` — официальная комбинированная M-версия логотипа (по брендбуку M-версия для размеров 321–780 px) с охранным полем.
- **Футажи кампании лежат в папке как ярлыки**, поэтому скачать их напрямую с сервера нельзя. Сделай свою копию:
  1. В папке кампании выдели 15–30 видео → правый клик → «Скачать».
  2. В своём Google Диске создай папку (например, `stalzone_footage`) и загрузи туда видео.
  3. Правый клик по папке → «Поделиться» → **«Все, у кого есть ссылка»** → «Копировать ссылку».
  4. Эту ссылку положи в секрет **`CLIP_SOURCES`**.
- Конвейер сам разбирается с длиной футажей:
  - **длинные** (от 75 секунд) — нарезает из них лучшие моменты;
  - **короткие B-roll** — **склеивает 5–9-секундные фрагменты из разных клипов** в динамичный монтаж на 45–60 секунд. Каждый фрагмент используется один раз.
- **Режим повтора** (`campaign.recycle`, включён): когда новый материал закончится, конвейер не остановится, а начнёт собирать ролики из фрагментов **старше 30 дней**: в новых сочетаниях, в другом порядке, с другими заголовками. Одинаковая склейка не повторяется никогда. Бот один раз напишет в Telegram, что включился повтор: если хочешь более свежие ролики, докинь в папку новые видео.

### 3. Telegram-бот для роликов и отчётов
1. В Telegram открой **@BotFather** → `/newbot` и скопируй токен.
2. Напиши своему боту любое сообщение (иначе он не сможет тебе писать).
3. Узнай свой chat id через **@userinfobot**.
4. В репозитории: Settings → Secrets and variables → Actions → **New repository secret**:
   - `TG_BOT_TOKEN` — токен бота
   - `TG_CHAT_ID` — твой id
   - `CLIP_SOURCES` — ссылка на папку с футажами: `https://drive.google.com/drive/folders/1ISG9LIUNZz8qduKKV_ozUNM6pq_piIzl`
5. Settings → Actions → General → **Workflow permissions** → **Read and write permissions** → Save.

### 4. Первый запуск
Actions → **daily-clips** → **Run workflow**. Через 15–30 минут ролики придут в Telegram.
Дальше конвейер запускается сам каждый день в 09:17 по Москве.

## Часть 2. Автовыкладка на YouTube (≈40 минут + ожидание аудита)

### 5. Проект в Google Cloud
1. console.cloud.google.com → войди **тем же Google-аккаунтом, где каналы** → создай проект `clipfarm`.
2. **APIs & Services → Library** → найди **YouTube Data API v3** → Enable.
3. **Google Auth Platform → Branding (OAuth consent screen)**:
   - тип **External**;
   - название, например `ClipFarm Scheduler`. Слово «YouTube» в названии использовать нельзя;
   - укажи свою почту.
4. **Audience → Publish app** (перевести в *In production*). Если оставить режим *Testing*, токены перестают работать через 7 дней.
5. **Clients (Credentials) → Create client → Desktop app**. Скачай JSON и переименуй его в `client_secret.json`.
6. Из этого JSON добавь в секреты GitHub:
   - `YT_CLIENT_ID` — значение `client_id`
   - `YT_CLIENT_SECRET` — значение `client_secret`

### 6. Токен канала (на своём компьютере, один раз на канал)
```
pip install google-auth-oauthlib google-api-python-client
python auth.py
```
- Откроется браузер. Google предупредит, что приложение не проверено: это твоё собственное приложение, нажми «Дополнительно → Перейти».
- **Выбери нужный канал** и разреши доступ.
- Скрипт спросит короткое имя (`main`) и напечатает строку вида `{"main": "1//0g..."}`.
- Создай секрет **`YT_TOKENS`** с этой строкой.

### 7. Подай на аудит
Заполни форму: support.google.com/youtube/contact/yt_api_form. Готовые ответы на английском лежат в **AUDIT.md**.

### 8. После одобрения
В `config.json` поменяй `"mode": "telegram"` на `"mode": "youtube"`. Всё, дальше ролики выкладываются сами.

До одобрения можно поставить `"youtube"` один раз для проверки: ролик загрузится, но останется приватным. Это нормально.

## Часть 3. Мультиаккаунты

Конвейер сразу рассчитан на несколько каналов.

1. Создай второй канал. Проще всего на том же Google-аккаунте: YouTube → Настройки → «Создать канал»; это будет канал бренда с отдельным названием.
2. `python auth.py` → выбери **второй канал** → имя `acc2`.
3. Обнови секрет `YT_TOKENS`, чтобы в нём были оба канала: `{"main": "...", "acc2": "..."}`.
4. В `config.json` у аккаунта `acc2` поставь `"enabled": true`. Слоты у него свои, чтобы ролики не выходили одновременно.
5. Привяжи канал в Клипни и пройди проверку кодом в описании.

Третий, четвёртый и следующие каналы добавляются так же: новый блок в `accounts` и новый ключ в `YT_TOKENS`.
Лимит API — 100 загрузок в день на проект, на 10+ каналов по 3 ролика хватает.

## Настройки `config.json`

| Поле | Что значит |
|---|---|
| `mode` | `telegram` / `youtube` / `local` |
| `campaign.sources` | запасной вариант: если секрет `CLIP_SOURCES` не задан, источники берутся отсюда |
| `campaign.banner` | плашка, накладывается на каждый ролик |
| `campaign.autoclip_args` | настройки нарезки (`--preset game --no-subs` для геймплея) |
| `campaign.recycle` | повтор старых фрагментов: `enabled` (вкл/выкл), `cooldown_days` (через сколько дней фрагмент можно использовать снова) |
| `campaign.montage` | монтаж из коротких футажей: `long_threshold` (с какой длины футаж считается длинным, сек), `target` (длина ролика), `piece` (длина одного фрагмента) |
| `campaign.hooks` | заголовки-хуки: пишутся в ролике и в названии, чередуются |
| `campaign.description`, `tags` | описание (с `#STALZONE`) и теги |
| `accounts[].clips_per_day` | сколько роликов в день на канал |
| `accounts[].slots` | время публикаций по Москве |
| `accounts[].title_format` | шаблон названия: `{hook}`, `{game}` |

`state.json` конвейер ведёт сам: там записано, какие отрезки уже нарезаны и что запланировано. Удалять его не нужно.

## Клипни
API у Клипни нет, поэтому ссылки отправляешь сам. Каждый день в Telegram приходит отчёт со ссылками: после времени публикации вставь их в «Отправить ролик» (около минуты в день).

## Лимиты GitHub
Репозиторий публичный, поэтому минуты Actions не ограничены и не тратятся из твоих 2000 минут для приватных проектов. Workflow запускается только в твоём аккаунте: в чужих копиях репозитория он не стартует.
