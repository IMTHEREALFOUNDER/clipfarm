# ClipFarm Scheduler — Privacy Policy

ClipFarm Scheduler is a private tool operated by a single individual to upload short video clips to their own YouTube channels on a schedule. It is not offered to or used by anyone else.

**Data accessed.** With the owner's consent (Google OAuth), the tool uses YouTube API Services to upload videos to the owner's channels and to read the owner's channel name once during authorization.

**Data stored.** The tool stores only OAuth refresh tokens (in an encrypted secret store) and the IDs of videos it uploaded. No other YouTube or Google user data is collected, stored, shared or sold.

**Third parties.** No data is shared with third parties.

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions. Stored tokens are deleted when access is revoked.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). Google Privacy Policy: https://policies.google.com/privacy
